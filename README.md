<h1>How to use it:</h1>
<h2>1. Download the folder</h2>
<h2>2. Enable in firefox settings to use user css</h2>
<h2>3. Go to about:support and then click open directory</h2>
<h2>4. Delete the folder called chrome(if existing)</h2>
<h2>5. Put the downloaded folder there and rename it to chrome</h2>
<h2>6. Kill all firefox processes and open it again</h2>
